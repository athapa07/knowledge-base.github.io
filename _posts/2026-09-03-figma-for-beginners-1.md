# Figma Shortcuts and Notes from the Figma Design for Beginners Course

Notes from working through the **Figma Design for Beginners 2025** course on YouTube. This is mainly a reference for future use, focusing on shortcuts, basic definitions, and a few settings that are worth remembering.

**Course:** [Figma Design for Beginners 2025](https://www.youtube.com/playlist?list=PLXDU_eVOJTx5IuSrbtanZHnDuPB3Hx0hq)

## Basic Tools

| Shortcut | Tool           |
| -------- | -------------- |
| **V**    | Move Tool      |
| **H**    | Hand Tool      |
| **T**    | Text Tool      |
| **F**    | Frame Tool     |
| **R**    | Rectangle Tool |
| **O**    | Ellipse Tool   |

**Space + V** — Move around the canvas.

## Frames, Groups and Sections

### Frame

A **frame** is a container for content. Frames are commonly used to build layouts and work with features such as Auto Layout.

### Group

A **group** is a collection of layers that can be treated as one object.

### Section

A **section** is used mainly to organise content on the canvas.

**Shift + S** — Create a Section.

> **Note to self:** Frame = container, Group = collection, Section = organisation.

## Moving and Nudging

| Shortcut              | Action       |
| --------------------- | ------------ |
| **Arrow Key**         | Move by 1px  |
| **Shift + Arrow Key** | Move by 10px |

Useful for making small positioning adjustments.

## Wrapping Content in a Frame

**Cmd + Option + G** — Wraps the selected content in a frame.

## Auto Layout

**Shift + A** — Add Auto Layout.

Auto Layout makes it easier to manage spacing and sizing when content changes.

For example, a button can increase in width when the text becomes longer instead of needing to be resized manually.

> **Note to self:** Auto Layout is one of the main things to get comfortable with.

## Components and Instances

### Component

A **component** is a reusable design element.

**Option + Cmd + K** — Create a Component.

### Instance

An **instance** is a copy of a component that remains linked to the original component.

**Option + Drag** — Create an Instance.

### Detach Instance

**Option + Cmd + B** — Detach an Instance.

This removes the link to the original component.

> **Note to self:** Component = reusable original. Instance = linked copy.

## Boolean Operations

These are used when working with overlapping shapes.

| Shortcut               | Operation | What it does                          |
| ---------------------- | --------- | ------------------------------------- |
| **Shift + Option + U** | Union     | Combines shapes                       |
| **Shift + Option + E** | Exclude   | Removes the overlapping area          |
| **Shift + Option + I** | Intersect | Keeps the overlapping area            |
| **Shift + Option + S** | Subtract  | Cuts one shape from another           |
| **Shift + Option + F** | Flatten   | Turns the result into a single vector |

Quick reminder:

* **Union** → combine
* **Exclude** → remove overlap
* **Intersect** → keep overlap
* **Subtract** → cut
* **Flatten** → single vector

## Fill and Stroke

**Shift + X** — Swap the fill and stroke.

## Selecting Matching Layers

**Cmd + Option + A** — Select matching layers.

Useful when the same change needs to be made to multiple similar elements.

## Prototyping

Most of the prototyping concepts were straightforward, but **Canvas Stacking** is one setting worth keeping as a reference.

**Auto Layout → Canvas Stacking → First on Top**

This controls which element appears on top when elements overlap.

> **Note to self:** Worth remembering for overlapping cards, menus, and similar layouts. This is the sort of setting that is easy to forget.
